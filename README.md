# About Me:
I am a Software Engineering student with hands-on experience in full-stack development, C++, SQL, and Linux. I build responsive and user-friendly web applications using React, Tailwind CSS, HTML, and CSS on the frontend, and NestJS with PostgreSQL on the backend. I am also skilled in designing and consuming REST APIs using Postman.<br><br>I enjoy creating solutions that are both functional and accessible, and I have experience collaborating on community-based and real-world projects. I thrive on problem-solving, learning new technologies, and contributing to projects that make a tangible impact.
